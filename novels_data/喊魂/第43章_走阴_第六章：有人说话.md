# 第四篇章《走阴》——第六章：有人说话

周远山四十八小时没睡觉了。

他不是刻意熬夜——是数据不让他睡。每次他准备站起来去泡杯咖啡然后回宿舍躺一会儿，屏幕上就会冒出一个他无法忽视的波形特征——然后他就坐下，把咖啡放在一边，忘了喝。四十八小时后他的桌面上堆了七杯喝到不同程度的咖啡——有的剩三分之一，有的只喝了一口。杯子之间的空隙里塞满了打印出来的频谱图、手写的计算草稿、以及四五个撕开的压缩饼干包装袋。饼干屑掉在键盘上——他懒得拍。

何知行在第四天凌晨两点路过理论研究室门口的时候，看到里面的灯还亮着。他敲了一下门。没人应。他推门进去——周远山坐在三块屏幕前面，眼镜推到额头上，左手按着一张手绘的信号流程图，右手在触控板上飞快地滑动。他的嘴里在低声念着什么——不是自言自语，是在跟计算对话。

"你在听自己说话？"何知行问。

周远山猛地回头——看到是何知行——松了一口气。然后把眼镜从额头抹下来。镜片上有一个清晰的手指印——油污。

"你已经两天没睡了——"

"我有结构。"周远山打断他。声音没有经过任何社交层——直接是结论。"源信号有结构。不是统计学意义上的非随机性——是语法。语法层面的结构。"

何知行拉了一把椅子坐下。没有说"你需要休息"。他知道周远山在这个时候需要的不是休息——是需要一个人听他把结论说完。他在周远山干了十三年——从来只在这种状态里看到两种东西：要么是失眠导致的偏执，要么是足以改写教科书的发现。周远山总是后者居多。

"给我看。"他说。

周远山把三块屏幕同时转过来。这三块屏像三联张画一样铺开——左边是老谭第一次走阴（失败）的源信号频谱，中间是第二次走阴（成功）的完整记录，右边是走阴前后的背景噪声对比。

"看第一次。"周远山指向最左边。"源信号出现后二十三秒——就被截断了。我做了脉冲间距的统计分布——它的间距不是均匀的，但也不是随机的。你看——'长—短—短—长—长—短'——这个间距模式在前两次出现时完全一致，然后突然中断——在这里。"他点了一个尖锐的反向脉冲。"这不是衰减。不是噪音覆盖。这是一个反向信号——倒相，振幅对等——精确匹配。像是——有人说了'不'。"

何知行盯着屏幕。他的手指在膝盖上敲了两下——不是习惯，是他在脑中推演。中微子自发产生精确倒相的反向脉冲——这在物理上可能的概率约为十的负十次方。除非——"除非是一个主动产生的抵消信号。"

"对。"周远山几乎跳起来。"不只是'拒绝'——是有人用同一个频率、同样的通道、发射了一道跟源信号恰好倒相的波形——把它消掉了。像两个人同时在说话，一个人声音把另一个人声音完全盖了过去——但盖的方式不是更响——是精确地波峰对波谷——直接对准——信号自己抵消自己。"

"一个通道。两个说话的人。"何知行的眉心出现了一道很窄的竖纹——他每次接近一个他不喜欢的结论时，那道竖纹就会出现。

"现在看第二次。"周远山把中间的屏幕放大——第二次走阴的完整信号记录。"四分钟零十七秒——从老谭进入δ波到他的心脏拉直——源信号的包络是慢上升的，这点我跟你说过。"

"说过。"

"但包络下面的微结构我是两个小时前才开始跑的。"周远山拉出一个细节放大部分。把信号的时间精度推到仪器采样率的极限——约零点三毫秒的单帧。"在极短时间内，这个信号不是连续的波形——是一个一个的"元"——离散的脉冲结构。脉冲之间的时间间隔不是随机的。它们组成了重复但不完全重复的模式。像——"

"像字母。"何知行说。

"像字母——但顺序不同，形成的意义不同。不是字母——更像——像单词。像构词法。"

何知行沉默了。

他不是在怀疑——他是在消化。源信号有"构词法"意味着它不是一个物理场——它是一个编码系统。有词汇、有结构、有可以被语义解释的底层逻辑。三十年来，749的科学家们试图用物理学的语言回答"源信号是什么"。如果它是一个编码系统——那问题变成：编码的来源是什么？是谁在用它？它要对谁说？

"你的意思是——源信号——"


"源信号在说话。"周远山站起来了。他的眼睛里有红血丝，但他的声音非常清醒。四十八小时没睡的大脑有时候比休息好的大脑更敏捷——不是逻辑更强，是过滤层更薄。"不是比喻。不是诗歌修辞。是数学上的'说话'——信号内部存在不等间距脉冲序列的自相关结构，其间距分布与人类语言中音位长度的分布没有统计上显著的差异。我用三组已知语言做对比——普通话、英语和日本京都方言——它的脉冲长度分布与三者都不相同，但它具有同样的——分布形态。语言不是声音——语言是结构。而这个信号——有结构。所以说它在'说话'。"

他顿了顿。咽了一口唾沫。嘴唇是干的。

"再说一件事——你坐稳。"

何知行已经被坐着的椅子稳住了三秒多。

"第二次走阴进入传话阶段的时候——就是老谭说出'她在'的那一瞬间——源信号的调制模式发生了瞬时切换。我跑了两台独立的信号分析平台——JUNO的原始数据和749自己的本地阵列——在相同的时间点。切换方式是：包络曲线的频谱密度分布在零点三毫秒内——重新配置了。从'散'到'聚'——从宽频到近零频的一个尖锐上升。光谱上是'聚焦'——对，物理学上叫聚焦。老谭在那一刻——像一个开关被拨到另一个位置。不是他自己拨的。"

何知行的手在膝盖上停下了。

"你的意思——是石婆——"

"我不知道那是谁。但参数上——它不是在回应老谭。它是接人。像是对话中有两个人原本在说——突然第三个人的声音从远处递到近处——音量不是渐强的——它本来就存在，只是刚才没被调到这个频道。老谭没有做任何操作——仪器记录证明他的手没有碰任何东西、脑波输入的底层调制不是他主动产生的变化。是他进了那扇门——然后有人从门的另一边把话筒接了过去。"

周远山拉回那张显示老谭心电直线的图。高频分量的回文结构——二进制正反读一致——在被打出来的灰白色纸张上显得格外刺目。

"心脏不只是泵。它在那个4.7秒里是一面镜子。"周远山圈出回文起止点。"在这个时间段里，老谭的心肌细胞不再是一个自激动节律系统——它停止了，你懂吗？何老师它没有跳——它的所有离子通道都静止，细胞膜电位趋零。在这种极端状态下，肌肉组织变成了一种被动电磁反射面——它不能发出信号，但可以反射信号。反射——且只反射源信号的那个特定频谱——"

"所以你看到的回文——不是老谭自己产生的——是源信号被反射回来的回波——"

"而且被编码了。"周远山咬着下嘴唇——下嘴唇被自己咬出了白痕。"回文源不是老谭。回文是在被反射之前就已经嵌在源信号里的——它在等一个反射面。老谭的心脏刚好在那个时间瞬间停搏——刚好提供了一个镜面。不是巧合。何老师。如果这是巧合——那我必须相信世界上有一万个猴子和一台打字机、它们同时打出了一句完整的回文诗歌——"


"源信号在回应他。"何知行终于说出了这句话。

房间里安静了大约十秒。安静到可以听到走廊里空调风的低频嗡嗡。

周远山没有点头。不是在辩论——是在警惕。他从打印纸堆里抽出一张——上面是他自己刚画的手绘图。源信号的整个频谱——从零点一赫兹到几个吉赫兹——在一个极简的坐标体系中被他分成了三个区段。

"低频段——这是老谭的脑波和心电重合的。这是'在'的意识层。中频段——这是他进入θ波以下时被截骨的。这是'通道'——两人对话的那层。高频段——"周远山的手停在最后一个区域上方——那一区里满是尖锐、密集、非周期性的脉冲。"——这是另一个人。"

"门卫。"何知行说。这个词不是从逻辑推理里来的——是他的直觉。老谭在第一次走阴被弹回来后说："有人替她拦"。周远山的频谱图区分了三个信号来源：一个正向的、插入式的、带有关键词密度极高脉冲序列的信号（"对话者"），一个与前者协作的、稳定提供通道支持的底层连续波（"通道"），以及一个在特定时刻突然激活、倒相、振幅对等——直接将对话者信号清零的反向信号（"那个东西"）。三个信号——不是同一个来源。

"门卫不是在阻止老谭——"周远山的声音慢了下来。"他在阻止石婆说话。老谭从第一次就被弹回来——因为门卫检测到了他的出现——但老谭不是重点。石婆才是。石婆的声音——那些含'名字'的插入式脉冲——是高密度信息。门卫容忍不了高密度信息通过通道。所以老谭进去时被拦——第二次石婆只有七个字能被传出来——第三次如果有——经过那个通道会被精确压缩到更少。"

"门卫——是什么？"何知行问。

周远山看着他。"我不知道。但不是'人'——它没有老谭和石婆那样的'结构动态'——它不变化。它是一个恒定的条件——像防火墙——它存在于通道内，但不是来自通道的任何一边。它始终在。只要源信号试图携带超过某个信息密度的内容通过——门卫就激活。这是信号论——不是鬼故事。但——"

他摘下眼镜。用衬衣下摆擦了擦镜片。衬衣扣错了两颗扣子——翻出来的衣摆边缘有咖喱的痕迹。

"——何老师——我们研究了三十年的源信号——我们一直以为它是一个'现象'。一种自然产生的中微子辐射异常。但自然不写回文。自然不做瞬时切换。自然没有两个说话人——一个说——一个拦——一个在前面当律法。这不是我们预期的那种信号。"

何知行摘掉眼镜。拿镜布擦了一下——镜布在指尖摩擦了两下。他的眉头那道竖纹比任何时候都深。

"你的意思是——"他说，声音很低。

"有人在用中微子说话。"周远山把眼镜戴回去——镜腿挂到了耳朵上。"不只是源信号有结构——源信号的'语法'处于在改变。它记住了。我们测了两次——两次信号不同——不是时间不同，是内容不同。它不是广播——是对话。而且——"他咽了一口唾沫——不是紧张——是多少意识到自己在说什么。"——它已经回答了我们的前几个问题。"

何知行捡起桌上那张回文序列的打印纸。他看了很久。然后从胸前的口袋里掏出那支用了大概十年的旧钢笔——笔尖在纸上划过一个字。

他写了两个字。

"门卫。"

写完后他盯着那两个字看了又看。然后推了一下眼镜。

"周远山——我知道你不需要——但是去睡两小时。"他起身走向门口。到门边的时候回头看了一眼屏幕。"数据跑不完。门卫跑不掉。但现在你也跑不动。"

周远山没有回答。他已经重新低下头。手在记号笔上——正在把新发现的一段不等间距脉冲序列标注为他刚刚定的临时代号：S-SIG-CHUNK-07——"语法片段-07"。铅笔旁边还挤了一行小字，是他自己刚加上的备注。

"已确认：信号中有两个独立的'说话者'——一个在给、一个在收、还有一个在扣。"

他画了一个圈——圈在"扣"上。然后把记号笔盖合上了。

窗外，北京的天边已经出现了一道极淡的白——不是天亮，是黎明前漫散射层的最早预兆。749园区里的银杏树在灰白色的天光里看起来像一排站在路边等待什么的瘦削轮廓。

周远山趴在桌上。没去宿舍。就趴在自己的打印纸堆上。压着那张回文序列图。左脸陷进一页被他划满了红线圈的频谱图——纸上还留着他最后一道墨迹未干的批注：

"源信号 ≠ 现象。源信号 = 语言。不是向我们广播的——是在回应我们。"
